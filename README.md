# ⌚ Tick & Style – Watch Store Website  

**Tick & Style** is a simple multi-page website for a fictional watch store.  
It was built using **HTML, CSS, and JavaScript** to practice the basics of front-end web development.  

---

## 📄 Pages  

- **Home Page** → Introduction to the brand with a banner and slogan  
- **Products Page** → Showcases watches with prices and a stock checker  
- **Contact Page** → A form to send name, email, and message (basic validation)  
- **Chat Page** → A chatbot interface that answers common store questions  

---

## 🎨 Features  

- Navigation bar on all pages  
- Footer with contact info (phone, email, location)  
- JavaScript chatbot with predefined answers  
- Simple and consistent design  
- Uses inline CSS (Home, Products, Contact) + external CSS (Chat)  

---

## 🚀 Technologies  

- **HTML5** → Structure  
- **CSS3** → Styling  
- **JavaScript (ES6)** → Chatbot + form validation  

---

## 💡 Purpose  

This project was made for **practice and learning**.  
It shows how to build a **basic multi-page website** with navigation, forms, interactivity, and a simple chatbot.  

---

## ⚡ How to Use  

1. Clone or download the repository  
2. Open `BSCS25056_Home.html` in your browser  
3. Use the navbar to visit the Products, Contact, and Chat pages
